## 🎯 Цель работы
Развертывание промышленного окружения веб-разработки (Python / Django) с подключением полноценной реляционной СУБД **PostgreSQL** и in-memory хранилища **Redis**.  
Создание базовой архитектуры информационной системы по теме **«Программа складского учёта» (Warehouse Management System)**: реализация кастомной модели пользователя со складскими ролями и базовых справочников складской номенклатуры.

---

## 🛠️ Стек технологий
* **Язык разработки:** Python 3.12
* **Фреймворк:** Django 5.1.4
* **База данных:** PostgreSQL 17
* **Кэширование и сессии:** Redis 8 (`django.core.cache.backends.redis.RedisCache`)
* **Драйвер БД:** psycopg2-binary 2.9.10
* **Управление окружением:** python-dotenv (принципы *12-Factor App*)
* **Контроль версий:** Git / GitHub

## 🏢 Модели предметной области

| Модель | Поля | Описание в системе складского учёта |
| :--- | :--- | :--- |
| **`User`** | `username`, `full_name`, `role` | Персонал склада: Администратор, Кладовщик, МОЛ (материально ответственное лицо), Аудитор-ревизор |
| **`Location`** | `name` | Склады, секции, зоны приемки, сортировки и временного хранения |
| **`Category`** | `name` | Категории товаров (Строительные смеси, Электроинструмент, Метизы, СИЗ и др.) |
| **`Vendor`** | `name` | Поставщики и производители (Knauf, Bosch Professional, Северсталь и др.) |
| **`Model`** | `name`, `vendor_id`, `category_id` | Складская номенклатура (конкретные товары с привязкой к поставщику и группе) |

## 🚀 Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/m0psiko/IT.git
cd IT
```

### 2. Создание и активация виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate  # для macOS/Linux
# или: .venv\Scripts\activate для Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` на основе шаблона `.env.example`:
```ini
SECRET_KEY=ваш-секретный-ключ
DEBUG=True
ALLOWED_HOSTS=*

POSTGRES_DB=ams
POSTGRES_USER=ams
POSTGRES_PASSWORD=ams
POSTGRES_HOST=localhost
POSTGRES_PORT=5432

REDIS_URL=redis://localhost:6379/1
```

### 5. Запуск служб и применение миграций
Убедитесь, что службы **PostgreSQL** и **Redis** запущены:
```bash
python manage.py migrate
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver 0.0.0.0:8000
```
Либо нажмите **F5** в VS Code.
